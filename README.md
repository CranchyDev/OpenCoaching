Open Coaching is a prototype project for a website focused on improving the gameplay, decision making and whatnot of a League of Legends player, from Iron to Challenger, and Pro Play in the future.

To be able to access this, you must use Visual Code Studio from Microsoft:

https://code.visualstudio.com/

Then open the project and make sure that you have Thymeleaf installed and Spring Boot Initializer.

NOTE: Visual Studio will probably prompt you to install the extensions when you try to open this project in any case, but it's good practice to install it beforehand.

You must also have java version 25 for this code to work.

And you must have a MySQL database ready for action too. Version 8+.

Before you run this, make sure that the MySQL database is actually running.

The db_dump. Is also included here so that you can quickly create it and get this up and running in no time.

Regarding the code, I tried to write things as best as possible with the help of our friends AI because this is the first time that I am doing this code and I was honestly running out of time. Hopefully, this can be improved in the future in case I still use Thymeleaf, which will most likely not be the case because I know that there are better options and more reliable and more "cloude based", so to speak out there.

Regardless, the code handles a Listing of CoachingSessions in the Schedule page.
You can ask for a coach which Adds a CoachingSession to a table within the database.
You can then Edit that CoachingSession within the Schedule page.
And you can also Remove that CoachingSession, still within the Schedule page.

The About and FAQ pages exist only for trivial factors.
